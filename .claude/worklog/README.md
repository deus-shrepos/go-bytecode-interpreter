# Work log

One entry per commit, written via `/worklog` before committing.
Files are named `YYYY-MM-DD-<slug>.md` and sort chronologically.

Each entry records: **What** (diff-scoped), **Why** (the trigger),
**How** (approach + decisions), **Evidence** (test/bench output),
and optionally **Stuck points**. Format is defined in
`.claude/skills/worklog/SKILL.md` — don't deviate from it.
